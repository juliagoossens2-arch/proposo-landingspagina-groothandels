# Proposo landingspagina — GitHub Pages

Upload `index.html`, `bedankt.html` en de volledige map `assets/` naar de root van de bestaande GitHub-repository. Laat het Netlify-project `proposo-team-3` ongemoeid.

## Belangrijk voor live campagne
- Het logo is overgenomen uit de door gebruiker gedeelde logoafbeelding. De magazijnfoto is een uitsnede van de gedeelde campagneposter; vervang door het originele losse fotobestand voor optimale kwaliteit.
- De externe brandguide en proposo.com konden tijdens deze bewerking niet worden geraadpleegd. Kleuren en lettertypes zijn daarom nog niet officieel geverifieerd.
- GitHub Pages verwerkt geen formulierinzendingen. De verzendknop is daarom bewust uitgeschakeld; koppel een geschikte formulierdienst of backend, voeg privacyverklaring toe, test een echte inzending en schakel pas dan de knop in.
- Controleer of de claim 'gratis advies' en de beschreven werkwijze kloppen.
